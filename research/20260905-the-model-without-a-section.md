## Craft

- Collapsed `<details>` print empty, and overriding the children's `display` does not help. `details::details-content { content-visibility: visible }` in a print media query does — verified against the generated PDF rather than assumed.
- Rendering the page to PDF and counting pages is a cheap way to check a layout claim. Ten to four, measured, instead of "feels shorter".
- Style rules that are written as a density have to be counted, not judged. The page sat at one em-dash per 55 words against a rule of one per 120, and the count before my edits was one per 56: left to itself, the draft calibrates against what is already there instead of against the rule.
- A generated copy is only in step when the generator runs. Changing the voice core silently dated Morten's transcript of it, and `sync-voice.py` had to be run in the same pass.
